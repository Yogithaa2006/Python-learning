# Day 4 - Multiplication Table Generator

## Overview
This Python program generates the multiplication table of a number entered by the user.

## Concepts Used
- Variables
- User Input
- Type Conversion
- Operators
- For Loop
- Formatted Output

## Example

Enter a number: 5

Multiplication Table of 5

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
...
5 x 10 = 50
