# Day 8 – Python String Methods

## 📌 Topic

Python String Methods:

* `split()`
* `strip()`
* `replace()`
* `format()`

## 📝 Project: Text Analyzer

This Python program accepts a word or sentence from the user and performs different string operations.

### Features

* Removes extra spaces using `strip()`
* Replaces spaces with underscores using `replace()`
* Splits the sentence into individual words using `split()`
* Counts the total number of words
* Counts the number of vowels
* Checks whether the entered text is a palindrome
* Displays results using `format()`

## 💻 Concepts Used

* Strings
* String methods
* `for` loop
* `if-else` statement
* String slicing
* User input
* Variables

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the following command:

```bash
python text_analyzer.py
```

4. Enter a word or sentence when prompted.

## 🧪 Sample Output

```text
Enter a word or sentence: Madam

----- TEXT ANALYSIS RESULT -----
Original text: Madam
Text after strip(): Madam
Text after replace(): Madam
Number of words: 1
Number of vowels: 2
Palindrome: Yes, it is a palindrome.
```
