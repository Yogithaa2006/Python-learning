#  Day 6 - Functions and Lists in Python

##  Project Title

**List Analyzer using Python Functions**

---




##  Objectives

- Practice Python Functions
- Learn Function Parameters and Return Values
- Work with Lists
- Use List Methods
- Understand List Slicing
- Implement Logic using Loops and Conditional Statements

---

## Features

- Accepts list elements from the user
- Displays the original list
- Reverses the list using slicing
- Finds the largest element manually
- Uses modular programming with separate functions

---

## Concepts Used

- Functions
- Parameters
- Return Statement
- Lists
- List Method (`append()`)
- List Slicing (`[::-1]`)
- For Loop
- If Statement
