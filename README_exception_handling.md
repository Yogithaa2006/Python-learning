# Day 10 - Exception Handling in Python

## 📌 Description

A simple Python division calculator that demonstrates exception handling using `try`, `except`, and `finally`.

## 🎯 Objective

To understand how Python handles runtime errors without stopping the entire program.

## 🧠 Concepts Learned

* `try` block
* `except` block
* `finally` block
* `ValueError`
* `ZeroDivisionError`
* Handling user input errors

## 💻 Program

The program accepts two numbers from the user and performs division.

It handles:

* Invalid input using `ValueError`
* Division by zero using `ZeroDivisionError`
* Program completion using `finally`

## ▶️ Sample Output

### Valid Input

```text
Enter the first number: 20
Enter the second number: 5
Result: 4.0
Program execution completed.
```

### Division by Zero

```text
Enter the first number: 20
Enter the second number: 0
Error: Cannot divide by zero.
Program execution completed.
```
