# Word Count Using File Handling in Python

## 📌 Description

This project is a simple Python program that reads text from a file and counts the total number of words present in it.

It is part of my **Day 9 Python Learning Journey**, where I learned the basics of **File Handling**.

## 🎯 Objective

To understand how to:

* Create and write data into a file
* Read data from a file
* Split text into individual words
* Count the total number of words

## 🛠️ Concepts Used

* `open()`
* File modes (`r`, `w`)
* `read()`
* `split()`
* `len()`
* `close()`

## 💻 Program

The program first creates a text file and stores a sentence in it. Then it reads the file, separates the content into words using `split()`, and counts the words using `len()`.

### Example Input

```text
Python is simple and powerful programming language
```

### Sample Output

```text
File Content:
Python is simple and powerful programming language

Total number of words: 7
```

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code or any Python IDE.
3. Run the following command:

```bash
python word_count.py
```

4. The program will display the file content and the total number of words.
