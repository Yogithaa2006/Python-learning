# Number Guessing Game

## Description

This is a simple Python console-based Number Guessing Game.

The program generates a random number between 1 and 100. The user has to guess the number. The program provides hints:

- Guess higher
- Guess lower

The game continues until the correct number is guessed.

## Concepts Used

- Python
- Variables
- User Input
- While Loop
- If-Elif-Else Statements
- Random Module

## How It Works

1. A random number is generated between 1 and 100.
2. The user enters a guess.
3. If the guess is too small, the program displays "Guess higher".
4. If the guess is too large, the program displays "Guess lower".
5. If the guess is correct, the program displays "You won!" and ends.

## Sample Output

Enter a number: 25

Guess higher

Enter a number: 75

Guess lower

Enter a number: 50

You won!
