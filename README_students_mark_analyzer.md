# Day 5 - Student Marks Analyzer

## Problem Statement

Create a Python program that manages student records using Python data structures.

The program should:

- Store student names and marks using a dictionary.
- Find the highest scorer(s).
- Calculate the average mark.
- Display unique marks using a set.
- Store topper details in a tuple.

## Concepts Used

- Dictionaries
- Sets
- Tuples
- Loops
- Conditional Statements
- Built-in Functions (max, sum, len)

## Sample Output

===== STUDENT MARKS ANALYZER =====

Student Records:
Arun: 85
Priya: 92
Kavin: 78
Meena: 88
Rahul: 92

Topper(s): Priya, Rahul
Highest Mark: 92

Average Mark: 87.0

Unique Marks: {88, 92, 85, 78}

Topper Details Tuple:
(['Priya', 'Rahul'], 92)

## Learning Outcome

This project demonstrates how tuples, dictionaries, and sets can work together in a real-world student record management system.
